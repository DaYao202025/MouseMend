### 四个设计决定

**① 快照加字段，而不是让窗口持有 `ContextFilter*`**

窗口只读快照、不持有引擎指针，这是既有架构。加字段比破坏它便宜。

**② 琥珀色独立于 `STRIP_LIT` 表**

```c
static const COLORREF STRIP_PAUSED_COLOR = RGB(0xC7, 0x7A, 0x2B);
```

暂停是**某一块的状态**，不是第五种能力状态。给 `STRIP_LIT[5][4]` 加一列会留下
四个空槽等人读错。

**③ 处理放在 `update_status_bar` 之后**

`refresh_capabilities` 拥有 `strip_state[0]`。先跑就会被它用钩子健康覆盖回绿色。
`refresh_capabilities` 里也加了 `if (!window->strip_paused)` 守卫。

**④ 只在显示的秒数变化时重设文字 + 重新测量**

```c
uint32_t left_s = snapshot.context_paused
                      ? (snapshot.context_pause_left_ms + 999u) / 1000u
                      : 0u;

if (snapshot.context_paused != window->strip_paused ||
    left_s != window->strip_pause_left_s)
{
    ...
    status_strip_set_caption(window, 0);
    status_strip_measure(hDlg, window);   // 数字多一位就要重测宽度
    InvalidateRect(GetDlgItem(hDlg, IDC_STATUS), NULL, FALSE);
}
```

不做"每 400ms 重绘"，也不做"不重测宽度"——后者会让倒计时末位被裁。

### 文案

| 语言 | 文案 |
|---|---|
| 中文 | `已暂停 · 剩余 %d:%02d` |
| 英文 | `Paused - %d:%02d left` |

暂停上限 720 分钟，所以最长是 `已暂停 · 剩余 720:00`。

### 又踩了一次同类错误
